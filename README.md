PROJECT NAME:-Rock-Paper-Scissors Game

Project Description:
This is a web-based application of the classic Rock-Paper-Scissors game. The user selects either Rock,Paper or Scissor, and the computer generates a random choice.The program compares both choices according to the rules 

Technologies Used:
1.HTML:-Creates the structure of the webpage
2.CSS:-Styles the interface and makes it visually appealing
3.JavaScript:-Provides the game's functionality by handling user input, generating the computer's random choice, determining the winner, updating the scores, and displaying the results dynamically without reloading the webpage.

Working:-
1.The user clicks on the rock,paperor scissor
2.Javascript generates a random choice 
3.The program compares both choices.
  i.Rock beats Scissors
  ii.Scissors beats Paper 
  iii.Paper beats Rock
  iv.Same choice results in a draw 
4.The result is displayed and the score is updated 

Features:
1.Interactive and user-friendly
2.Play with andom oppoonent
3.Real-time result display
4.Score tracking for players
